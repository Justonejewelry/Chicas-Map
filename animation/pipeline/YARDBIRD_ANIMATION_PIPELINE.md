# YardBird Animation Pipeline
## Yowl Lawnda · Pixar-Inspired Production System
**Version 1.0 · Atlas · Project YardBird / GSIN · 2026-08-01**

## Mission
Produce top-of-the-line character animation for Yard-Bird Update editions with continuous natural motion, consistent character performance, accurate live intelligence, and broadcast-ready delivery.

## Pipeline Stages (Pixar mapping)

| # | Stage | Pixar analog | YardBird implementation |
|---|-------|--------------|-------------------------|
| 0 | Development | Story / character design | Character bible, voice bible, episode brief |
| 1 | Story | Storyboards / reels | Shot list + timed beat sheet from forecast intel |
| 2 | Editorial | Animatic | Rough timing cut with temp audio + proxy frames |
| 3 | Layout | Layout / camera | Frame composition, map safe-areas, lower-third zones |
| 4 | Animation | Blocking → spline → polish | Multi-pose keyframes → optical-flow interpolate → polish |
| 5 | Character FX | Secondary action | Ear bob, harness glint, sparkle cycles |
| 6 | Effects | FX | Pin pop-ins, heat-map pulses, confetti |
| 7 | Lighting / Look | Lighting | Color script, grade LUT, brand palette lock |
| 8 | Compositing | Comp | Overlay intel, badges, titles, audio-driven mouth cycles |
| 9 | Sound | Sound design / mix | VO + beds + whooshes + pin hits |
| 10 | Final Delivery | DI / master | H.264 / ProRes masters, platform crops, archive |

## Character System — Yowl Lawnda

## Quality bar
- Continuous motion (no pure still > 0.4s without micro-motion)
- Character consistency vs model sheet
- Intel accuracy vs neighborhood clusters for air date
- VO not clipped; CTA clean
- Master ≥ 1280×720 (prefer 1080p)
