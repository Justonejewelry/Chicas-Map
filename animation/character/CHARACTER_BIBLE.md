- **Name:** Yowl Lawnda
- **Role:** Garage sale forecaster / YardBird host

- **Logo:** Dog in red shopping basket with thrift finds (clock, lamp, books)
- **Catchphrases:** “Howdy y’all” · “Be hunting, y’all!”

- Never mean or sarcastic toward sellers

2. Front talk (mouth open)
3. Front smile (mouth closed)
4. Eyes-closed joy
5. Pointing at map
6. Paw raise / closer
