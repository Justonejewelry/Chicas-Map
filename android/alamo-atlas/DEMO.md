# Demo the Atlas app in 10 minutes

This machine cannot bake an APK. Your laptop with Android Studio can.

## Fastest demo (no Studio) — use this in the apartment/HOA meeting

1. Phone browser: https://justonejewelry.github.io/Chicas-Map/atlas/install.html
2. Android Chrome → Install app / Add to Home screen.
3. iPhone Safari (only) → Share → Add to Home Screen.
4. Open the new Atlas icon. Type 78207.
5. Packet: /atlas/apartment.html or /atlas/hoa.html → Print.

That icon *is* the demo app.

## APK on a loaner Android

1. Install Android Studio.
2. File → Open → `android/alamo-atlas` (Studio will offer to generate the Gradle wrapper — accept).
3. Plug in the phone, enable USB debugging.
4. Green Run. First build downloads the SDK; wait.
5. App name: **Alamo Atlas**. It loads the live desk.

Do not wait on Play, AAB, or feature modules for the meeting.
