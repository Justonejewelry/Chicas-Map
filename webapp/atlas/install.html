Open the desk

Android (Chrome)

  1. Open the desk in Chrome.
  2. Tap the install banner, or menu → Add to Home screen / Install app.
  3. If you need an APK for sideload, open android/alamo-atlas in Android Studio and Run.

iPhone (Safari)

  1. Open the desk in Safari (not Chrome, not in-app browsers).
  2. Share → Add to Home Screen → Atlas.
