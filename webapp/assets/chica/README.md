# Official Chica photos (Meet Chica)

**Identical likeness only — use the real Chica photos.**

**Never use "meat-cheeks" or any variant. Correct branding is Meet Chica / Meet Cheeks.**

Drop these four files in this folder (exact names):

| File | Photo |
|------|--------|
| `smile.jpg` | Chica on her back, big smile / teeth (Meet Chica) |
| `cape.jpg` | Chica in the sparkly blue superhero cape |
| `napping.jpg` | Sleeping on purple blanket, tongue out |
| `adventures.jpg` | Pink Safe harness, with her human |

Upload via GitHub web UI:
1. Open https://github.com/Justonejewelry/Chicas-Map/tree/main/webapp/assets/chica
2. **Add file → Upload files**
3. Drag the four photos and rename to match the table
4. Commit

They power **Chica's Backyard → Meet Chica** and the backyard header avatar.

Also create `webapp/assets/videos/` and place `chica_highway_adventure.mp4` there for the featured adventure player.
