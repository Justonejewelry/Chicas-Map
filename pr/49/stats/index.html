Upcoming pins
Sales that have not ended yet

How many sales in the public feed have not ended yet. If a sale’s last day has already passed in Central Time, it is left out. The source is the live sales file that powers the map.

Coming soon
Site visits
Public traffic counter

Unique visits from both of the site’s public GoatCounter visitor counters, the current one and the older one, added together. If neither counter answers, this card shows “Coming soon” instead of a made-up number.

Weekend countdown

What’s open right now, what’s still ahead this Friday–Sunday, and when the next sale opens. Times are Central Time.

Open now means this sale is on today’s calendar and Chica has posted hours that include the current Central Time. Sales without hours are not marked open. Still ahead are this weekend’s sales that have not started yet. The countdown uses the next posted opening time. Monday through Thursday, this panel also tells you when Friday arrives.

This weekend by area

Neighborhoods shaded by how many sales are on the map this Friday–Sunday. Darker pink means more pins.

A weekend heat map of the same neighborhoods used on Chica’s map, based on each sale’s ZIP code and the live sales feed. Circle size and color follow the pin count. Some sales sit outside this city view and are listed under Other area. The map uses the same map library as the rest of the site.

By neighborhood

Upcoming pins in each area, using the sale’s ZIP code.

Upcoming sales grouped by the same neighborhoods used on the map, based on each sale’s ZIP code. A sale without a known ZIP lands in “Other area.”

Where listings come from

How the sales still on the map were found.

Facebook, email leads, Nextdoor, and public listing sites, taken from each sale’s source field in the live feed. Chica does not invent these categories.

Newest sales added

The most recently posted or reviewed listings that still have an added date.

Sales with the latest posted or reviewed date. Many listings do not include that date, so those are left off this list rather than guessed. Each link opens the sale on the map.
